# CelLove

A sandbox game based on Cell Machine by Sam Hogan, built with [LÖVE 11.5](https://love2d.org).

## Running

Install LÖVE 11.5 and run it from root:

```
love .
```

Release builds for Windows, Linux, macOS and Android are available on the Releases page.

## Modding

Cells, texture packs and mods are documented in [`docs/`](docs/Home.md) (also published to the [wiki](../../wiki)).
